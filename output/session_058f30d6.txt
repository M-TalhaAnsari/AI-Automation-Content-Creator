  Zero‑shot mBART model
  Streamlit interactive UI
  Deploy on Heroku

  🔗 LINK
  https://github.com/huggingface/transformers

  ✍️  CAPTION
  Project Overview: A web app that takes a news article URL, detects its language, and produces a concise 3‑sentence summary using the multilingual mBART model. 🌍✂️
  
  Tech Stack Breakdown: Hugging Face 🤗 Transformers, mBART‑large‑50, Python, Streamlit for the front‑end, Requests for scraping, and Heroku for one‑click deployment.
