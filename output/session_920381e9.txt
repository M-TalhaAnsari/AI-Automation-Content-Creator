  Docker‑Compose local dev environment

  🔗 LINK
  https://www.projectpro.io/article/artificial-intelligence-project-ideas/461

  ✍️  CAPTION
  **Project Overview**
  Instead of a single chatbot, this project builds a team of purpose‑built agents that collaborate to handle complex workflows—scheduling meetings, summarizing emails, and fetching research—all without a monolithic ML model. 🌟
  
  **Tech Stack Breakdown**
  - Microsoft AutoGen SDK (Python)
  - FastAPI gateway for inter‑agent messaging
  - Docker‑Compose for isolated services (EmailAgent, CalendarAgent, ResearchAgent)
  - Redis Pub/Sub for real‑time coordination
  - Azure OpenAI for LLM calls
  
  **Core System Architecture**
  1️⃣ User request hits the FastAPI gateway.
  2️⃣ The gateway routes the intent to the appropriate agent via Redis.
  3️⃣ Each agent runs its own prompt chain, calls Azure OpenAI, and returns a result.
  4️⃣ A coordinator agent merges responses and sends a unified reply back to the user.
  5️⃣ All logs flow to Azure Monitor for debugging.

  POST 3/5 — LLM‑Driven Email & SharePoint Automation Blueprint
────────────────────────────────────────────────────────────

  🔥 HOOK
  📧 Turn chaotic inboxes into smart workflows with just a prompt.

  📌 SUMMARY
  RAG‑enabled LLM engine
  Email & SharePoint connectors
  ECS + CloudWatch monitoring

  🔗 LINK
  https://www.youtube.com/watch?v=aIi4ehYFtls

  ✍️  CAPTION
  **Project Overview**
  Automate routine office tasks—like filing attachments to SharePoint, drafting replies, or flagging urgent tickets—by feeding raw email content into a Retrieval‑Augmented Generation (RAG) pipeline. No hard‑coded rules, just context‑aware AI. ✉️
  
  **Tech Stack Breakdown**
  - Python FastAPI service
  - LangChain RAG layer with Azure Cognitive Search
  - Microsoft Graph API for Email & SharePoint access
  - Dockerized deployment on AWS ECS
  - CloudWatch Logs & Alarms for reliability
  
  **Core System Architecture**
  1️⃣ Email webhook triggers the FastAPI endpoint.
  2️⃣ The service extracts content, queries the knowledge base via Azure Search, and builds a RAG prompt.
  3️⃣ LLM generates the appropriate action (reply, move, tag) and returns a JSON command.
  4️⃣ The command is executed via Microsoft Graph, and every step is logged to CloudWatch.
  5️⃣ A simple UI (React) shows processing status and audit trails.
