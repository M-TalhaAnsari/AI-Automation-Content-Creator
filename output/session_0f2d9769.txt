  🔗 LINK
  https://codebasics.io/blog/5-production-ready-ai-projects-to-build-in-2026

  ✍️  CAPTION
  Project Overview:
  An end‑to‑end pipeline that reads scanned invoices, extracts line items, totals, and vendor info, then stores them in a relational DB for analytics.
  
  Tech Stack:
  - LayoutLMv3 (Microsoft) for table detection
  - PyMuPDF for PDF handling
  - SQLAlchemy + PostgreSQL
  - Docker‑Compose, CI/CD with GitHub Actions, deployed on GCP Cloud Run
  
  Core System Architecture:
  🔹 Ingestion Service → OCR → LayoutLMv3 model → Entity extraction
  🔹 Validation microservice (rules engine) → Normalization
  🔹 Persistence layer writes to PostgreSQL, triggers a webhook for downstream ERP.
