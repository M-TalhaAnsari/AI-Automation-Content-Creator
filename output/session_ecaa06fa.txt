  POST 1/5 — InstaStyle Transfer: AI‑Driven Fashion Filter
────────────────────────────────────────────────────────────

  🔥 HOOK
  🚀 Turn any selfie into runway‑ready art in seconds!

  📌 SUMMARY
  TensorFlow 2.x with tf.keras
  Custom MobileNetV2 style encoder
  Deploy as TensorFlow Lite on Android/iOS

  🔗 LINK
  https://github.com/tensorflow/tensorflow

  ✍️  CAPTION
  Project Overview:
  Imagine an Instagram filter that instantly applies high‑fashion styles to any portrait. InstaStyle Transfer does exactly that—leveraging deep neural style transfer to remix user images with curated runway palettes.
  
  Tech Stack:
  - TensorFlow 2.x core with tf.keras functional API 📦
  - Pre‑trained MobileNetV2 as the encoder for speed
  - Style decoder built from residual blocks, trained on a curated fashion dataset
  
  Core Architecture:
  1️⃣ Upload image → 224×224 preprocessing
  2️⃣ Encoder extracts content features
  3️⃣ Style vectors blended via Adaptive Instance Normalization
  4️⃣ Decoder generates stylized output, then converted to TensorFlow Lite for on‑device inference (≈30 ms per frame).

  POST 2/5 — CaptionCraft: GPT‑style Instagram Caption Engine
────────────────────────────────────────────────────────────

  🔥 HOOK
  💡 What if your phone wrote viral captions for you?

  📌 SUMMARY
  🤗 Transformers with GPT‑2 fine‑tuned on Instagram captions
  Beam search + emoji injection
  Serve via FastAPI on AWS Lambda

  🔗 LINK
  https://github.com/huggingface/transformers

  ✍️  CAPTION
  Project Overview:
  CaptionCraft is a lightweight service that generates scroll‑stopping captions, complete with emojis and hashtags, tailored to your image content.
  
  Tech Stack:
  - HuggingFace Transformers library, GPT‑2 base model 🤖
  - Fine‑tuned on 200k public Instagram captions scraped via the Instagram Graph API
  - Post‑processing layer adds context‑aware emojis using a custom emoji‑lexicon
  
  Core Architecture:
  🔹 Input image → CLIP encoder extracts visual tokens
  🔹 Tokens fed into GPT‑2 decoder with beam search (width 5)
  🔹 Emoji injector selects top‑3 emojis based on sentiment scores
  🔹 FastAPI endpoint returns JSON payload in <200 ms, hosted on AWS Lambda for auto‑scaling.

  ✍️  CAPTION
  Project Overview:
  EngagePulse predicts the swipe‑up conversion probability of an Instagram Story using historical performance data, so creators can iterate before publishing.

  4️⃣ Azure Function exposes a REST endpoint; front‑end UI shows predicted CTR in real time.

  POST 4/5 — CarouselMatch: AI‑Curated Multi‑Image Carousel Builder
────────────────────────────────────────────────────────────

  🔥 HOOK
  🖼️ Let AI stitch the perfect carousel that converts!

  📌 SUMMARY
  Deep Learning models from D2L (ResNet + BERT)
  Cross‑modal similarity scoring
  Dockerized service on GCP Cloud Run

  🔗 LINK
  https://github.com/d2l-ai/d2l-zh

  ✍️  CAPTION
  Project Overview:
  CarouselMatch automatically selects and orders up to 10 images for an Instagram carousel, optimizing for visual harmony and audience relevance.
  
  Tech Stack:
  - D2L‑zh implementations of ResNet‑50 (image encoder) and BERT‑base (text encoder) 📖
  - Cross‑modal similarity matrix computed via cosine similarity
  - Docker container orchestrated on Google Cloud Run for instant scaling
  
  Core Architecture:
  🔸 Upload a folder of candidate images + optional caption keywords
  🔸 ResNet extracts visual embeddings; BERT processes caption intent
  🔸 Similarity scores rank images; a greedy algorithm assembles the top‑scoring sequence respecting aspect‑ratio constraints
  🔸 API returns ordered image URLs and suggested captions.

  POST 5/5 — MoodLens: Emotion‑Aware Instagram Filter Selector
────────────────────────────────────────────────────────────

  🔥 HOOK
  😎 Your mood decides the filter—automatically!

  📌 SUMMARY
  TensorFlow CNN for facial emotion
  Transformers for caption sentiment alignment
  Edge deployment via TensorFlow.js in browser

  🔗 LINK
  https://github.com/tensorflow/tensorflow

  ✍️  CAPTION
  Project Overview:
  MoodLens reads your facial expression in real time, matches it to a curated set of Instagram filters, and even suggests a caption that mirrors your vibe.
  
  Tech Stack:
  - TensorFlow CNN (mini‑VGG) trained on FER‑2013 for emotion detection 🎭
  - HuggingFace Transformers (DistilBERT) fine‑tuned on sentiment‑aligned captions
  - Front‑end built with TensorFlow.js for on‑device inference (no server latency)
  
  Core Architecture:
  1️⃣ Webcam feed → 48×48 grayscale → CNN predicts emotion (happy, sad, surprised…)
  2️⃣ Detected emotion maps to filter preset (e.g., “Warm Glow” for happy)
  3️⃣ DistilBERT generates a short caption matching the emotion tone
  4️⃣ UI overlays filter preview and caption suggestion instantly.
