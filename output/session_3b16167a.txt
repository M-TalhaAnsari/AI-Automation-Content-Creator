  📌 SUMMARY

  Fast Flask API wrapped in Docker
  Deployed on AWS Elastic Beanstalk

  🔗 LINK
  https://hackernoon.com/top-5-machine-learning-projects-for-beginners-47b184e7837f

  ✍️  CAPTION
  Project Overview:
  We built a full‑stack movie recommendation system using the classic MovieLens dataset, turning raw ratings into personalized suggestions.
  
  Tech Stack:
  Python pandas for data wrangling, Scikit‑learn’s Surprise library for matrix factorization, Flask for the inference API, Docker for containerization, and AWS Elastic Beanstalk for scalable hosting.
