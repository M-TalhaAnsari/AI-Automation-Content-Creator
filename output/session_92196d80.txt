────────────────────────────────────────────────────────────

  🔥 HOOK
  🌿 What if your phone could diagnose wilted leaves in seconds?

  📌 SUMMARY
  CNN trained on 30k+ leaf images
  TensorFlow Lite model for Android
  Edge deployment via Google Play Store

  🔗 LINK
  https://github.com/tensorflow/tensorflow

  ✍️  CAPTION
  Project Overview:
  Imagine walking through your garden and instantly knowing which plant is sick. This project trains a convolutional neural network on a curated dataset of common crop diseases and exports it to TensorFlow Lite for on‑device inference.
  
  Tech Stack:
  🔹 Python + TensorFlow 2.x for model development
  🔹 TensorFlow Lite Converter for quantization
  🔹 Android Studio (Kotlin) for the mobile UI
  
  Core System Architecture:
  1️⃣ Data pipeline pulls images from a public plant‑disease repo, augments them, and feeds them into a ResNet‑50 backbone.
  2️⃣ After training, the model is frozen, quantized, and packaged as a .tflite file.
  3️⃣ The Android app loads the model, captures a leaf photo, runs inference locally, and displays a confidence‑scored diagnosis with treatment tips.

  POST 4/5 — Dynamic Handwriting Style Transfer for Chinese Calligraphy
────────────────────────────────────────────────────────────

  🔥 HOOK
  🖌️ Teach a neural net to write Chinese characters in your grandma’s style!

  📌 SUMMARY
  CycleGAN on 10k glyphs
  PyTorch backend with custom loss functions
  Flask‑WebGL demo for real‑time rendering

  🔗 LINK
  https://github.com/d2l-ai/d2l-zh

  ✍️  CAPTION
  Project Overview:
  Preserve heritage by training a GAN to mimic a specific calligrapher’s brush strokes. Users upload a sample sheet, and the model renders any requested character in that unique style.
  
  Tech Stack:
  🔹 PyTorch for the CycleGAN architecture
  🔹 D2L‑zh notebooks for data preprocessing and training utilities
  🔹 Flask server + WebGL canvas for instant browser rendering
  
  Core System Architecture:
  1️⃣ Collect 10,000 paired glyph images from the target style and a generic font set.
  2️⃣ Train a CycleGAN with identity and style‑preservation losses to map between domains.
  3️⃣ Export the generator as a TorchScript module for fast inference.
  4️⃣ Flask endpoint receives a Unicode character, runs the generator, and streams the SVG back to the front‑end where WebGL paints the brush‑stroke animation.
